# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript — no frameworks. Showcases my profile, skills, projects, and achievements in a clean, single-page layout.

## Features

- **About Me** — short intro and background
- **Skills** — animated progress bars for core skills
- **Projects** — card-based project showcase with tags and links
- **Achievements** — timeline of milestones
- **Contact** — quick links to email, GitHub, and LinkedIn
- Fully responsive layout (mobile, tablet, desktop)
- Sticky navigation with a mobile hamburger menu
- Hover effects and subtle load-in animations
- Respects `prefers-reduced-motion` for accessibility

## Tech Stack

- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript (mobile nav toggle)
- Google Fonts (Fraunces, Inter)

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/personal-portfolio.git
   ```
2. Open `index.html` directly in your browser — that's it.

## Deployment

Deployed with **GitHub Pages**:
1. Push the repo to GitHub.
2. Go to **Settings → Pages**.
3. Set source to the `main` branch, root folder.
4. Your site will be live at `https://<your-username>.github.io/personal-portfolio`.
